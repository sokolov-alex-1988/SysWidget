======================================================================
 ВИДЖЕТ СИСТЕМЫ — КАК ЗАПУСТИТЬ (версия 1.0.0)
======================================================================

 Компактная карточка на экране: загрузка ОЗУ, ЦП, физических дисков
 (SSD/HDD), видеокарты и сетевой активности, а также строки подключённой
 периферии — мыши, клавиатуры, наушников — со значком типа и зарядом.
 Значок в области уведомлений — живой «цифровой дождь», который краснеет
 при перегрузке; освобождение оперативной памяти, окно мониторинга,
 настройки и два языка. Темы оформления: неон, тёмная и светлая.

----------------------------------------------------------------------
ЧТО ЛЕЖИТ В ПАПКЕ
----------------------------------------------------------------------

  SysWidget.exe              само приложение
  SysWidget.exe.config       обязателен рядом с exe (масштаб на разных
                             мониторах). Без него не запускайте.
  icon.ico                   иконка ярлыков и окон
  portable.flag              (только в переносном архиве) пустой файл:
                             пока он лежит рядом с exe, настройки хранятся
                             в этой же папке — удобно для флешки
  КАК ЗАПУСТИТЬ.txt          этот файл
  README.md, CHANGELOG.md    описание проекта (русский и английский) и история версий
  LICENSE                    лицензия PolyForm Noncommercial 1.0.0: некоммерческое
                             использование свободно, коммерческое — по разрешению автора

  SysWidget — код с пояснениями.txt   как устроено и где что править
                             (для разработки; для работы не нужен)

 Где хранятся настройки
  * обычный запуск — папка %LOCALAPPDATA%\SysWidget (там же error.log,
    если что-то пошло не так). Работает и из Program Files;
  * переносной режим (рядом с exe есть portable.flag) — рядом с exe;
  * если папка в профиле недоступна для записи, настройки лежат рядом
    с exe;
  * старые настройки (state.json, alerts.json, window.json), лежавшие
    рядом с exe, при первом запуске копируются в папку данных сами.

 Файлы настроек (появляются по мере использования):
  state.json      место карточки, её вид, язык
  alerts.json     пороги оповещений, тихие часы
  window.json     место и размер окна настроек
  dashboard.json  размер, место и период графика окна мониторинга
  history.txt     история нагрузки за последние сутки по минутам (графики
                  «1 ч» и «24 ч» в окне мониторинга)
  prefs.json      вид и поведение: тема, плотность, шрифт, цвета,
                  прозрачность, подписи, кнопка «▦», цвет по нагрузке,
                  имя Wi-Fi в подсказке, лимит трафика
  traffic.json    счётчики трафика за день и месяц
  periph.json     журнал подключений и заряда периферии
  net.json        необязательный, создаётся вручную: узел для пинга
                  {"PingHost":"…"}; программа его только читает
  error.log       создаётся, только если что-то пошло не так

 Их можно удалить — тогда настройки вернутся к значениям по умолчанию.
 Кнопка «Открыть» в Настройки → «Данные» → «Папка данных» открывает эту
 папку в проводнике.

----------------------------------------------------------------------
ЧТО НУЖНО
----------------------------------------------------------------------

  * Windows 10 версии 1903 или новее либо Windows 11.
  * .NET Framework 4.8 — в этих версиях Windows он уже установлен.
  * Права администратора НЕ нужны. Драйверы НЕ нужны. Единственное
    необязательное исключение — «Расширенные данные» (Настройки →
    Система): по кнопке с запросом UAC даёт температуру и износ диска.
  * Устанавливать ничего не надо: программа не создаёт служб и не кладёт
    файлы в системные папки. В реестр она пишет только в одном случае:
    кнопки «Отключить» / «Включить» в списке автозагрузки (Настройки →
    Система) ставят флаг в вашей ветке StartupApproved, как диспетчер
    задач.

----------------------------------------------------------------------
КАК ЗАПУСТИТЬ
----------------------------------------------------------------------

 1) Скопируйте ВСЮ папку SysWidget в удобное место, например:
       C:\Users\<имя>\SysWidget
    Важно: папка должна быть доступна на запись обычному пользователю.
    В C:\Program Files настройки молча не сохранятся.

 2) Запустите SysWidget.exe (двойной щелчок).

 3) Появится карточка и значок в области уведомлений. При запуске в меню
    «Пуск» создаётся ярлык «Виджет системы» (в английском интерфейсе —
    «System widget») — через него программу удобно запускать потом.

 Если Windows покажет «Windows защитила ваш компьютер»:
    «Подробнее» → «Выполнить всё равно». Это стандартное предупреждение
    для файла без цифровой подписи.

----------------------------------------------------------------------
УПРАВЛЕНИЕ
----------------------------------------------------------------------

  Карточка
    * перетащить мышью — в любое место экрана, в том числе на панель
      задач (там она сама подстроится по высоте);
    * одиночный клик по строке (ЦП, ОЗУ, диск, ГП, сеть, периферия) —
      плашка с подробностями; для ЦП и ОЗУ это «топ процессов»
      (см. ниже). По пустому месту карточки клик ничего не открывает;
    * правый клик — меню;
    * правый клик по любой строке (ОЗУ, ЦП, диск, ГП, сеть,
      периферия) — меню строки «Скрыть строку»;
    * кнопка «молния» — освободить оперативную память;
    * кнопка «▦» — окно мониторинга (см. ниже); её можно скрыть:
      Настройки → «Вид» → «Кнопка «▦» на карточке»;
    * кнопка «⚙» — открыть настройки;
    * Ctrl+Alt+W — показать/скрыть карточку с любого места (сочетание
      жёстко задано; если оно занято другой программой, виджет
      работает без него).

  Топ процессов
    * клик по строке ЦП или ОЗУ открывает плашку над карточкой: шесть
      самых «тяжёлых» процессов, одноимённые сложены в одну строку
      («chrome ×23»); для ЦП — загрузка, для ОЗУ — занятая память;
      у диска, ГП и сети плашка устроена так же (процессы по вводу-
      выводу, по загрузке ГП, по соединениям);
    * плашка обновляется раз в секунду-полторы, пока она открыта, и
      закрывается сама через несколько секунд после ухода курсора;
      повторный клик по той же строке тоже закрывает её;
    * справа у процесса — «✕»: первый клик спрашивает «Завершить?»,
      второй завершает все процессы с этим именем; у системных
      процессов, проводника и самого виджета крестика нет;
    * клик по тревоге ЦП или ОЗУ («… · клик — что грузит») открывает
      ту же плашку.

  Мини-графики
    * клик по строке метрики открывает плашку; в её шапке — график
      за последние 2 минуты и строка «за N мин: ср … · макс …»
      (при наведении лишь слабая подсветка строки, подсказок нет);
    * история хранится в двух слоях: последние 15 минут — по секундам, только
      в памяти (после перезапуска она начинается заново); последние сутки — по
      минутам (среднее и пик каждой минуты) в файле history.txt, он пишется раз
      в 5 минут и при выходе. Поэтому графики «1 ч» и «24 ч» в окне мониторинга
      переживают перезапуск; минуты, когда виджет не работал, остаются пустыми,
      и линия на графике в этих местах прерывается.

  Сеть на карточке
    * «Сеть ↓X ↑Y» — приём и передача в МБ/с через тот адаптер, по
      которому сейчас идёт трафик (Wi-Fi или Ethernet); виртуальные
      и служебные адаптеры (Hyper-V, TAP, Bluetooth) не учитываются
      и не дублируют скорость;
    * в простое — «↓0.0 ↑0.0» приглушённым цветом;
    * клик по строке — плашка с подключением (Wi-Fi или кабель) и
      скоростью канала, пингом до шлюза и потерями (узел можно задать
      в net.json), трафиком за сегодня и за месяц (считается, пока
      виджет запущен), процессами с соединениями и графиком за 30 дней.

  Периферия на карточке
    * после метрик идут строки подключённых устройств — мыши,
      клавиатуры, наушников: только значок типа и заряд;
    * если мышь и клавиатура работают через общий USB-приёмник
      2,4 ГГц, строка одна, но с двумя значками — мышь и клавиатура;
      заряд такого приёмника Windows не отдаёт, поэтому справа «USB»;
      по Bluetooth каждое устройство показывается отдельной строкой;
    * если заряд недоступен — тип подключения («USB» или «BT»);
    * модель, производитель и остальные сведения — в плашке по клику
      на строку;
    * заряд: 100–50 % зелёный, 49–20 % оранжевый, 19–0 % красный;
    * сопряжённые, но не подключённые устройства не показываются:
      они не используются;
    * чип «Периф.» в настройках и пункт меню «Периферия» скрывают
      и возвращают эти строки; то же делает «Скрыть строку» в меню
      строки периферии.

  Окно мониторинга
    * открывается кнопкой «▦» на карточке или пунктом «Окно мониторинга»
      в меню; одна строка на ОЗУ, ЦП (со столбиками по ядрам), каждый
      диск, ГП и сеть: слева значение (жёлтое от порога «Жёлтый от», красное от «Красный от»
      в настройках «Вид») и «за N: ср … · макс …»,
      в середине график со шкалой времени, справа подробности;
    * под заголовком — полоса «что сейчас нагружает ПК»: зелёная точка и «Всё в
      порядке», либо жёлтая/красная точка и фраза с виновником, например «Процессор
      загружен (81%): chrome — 40%» или «Диск C: занят на 95%: больше всего X пишет
      80 МБ/с». Считается по порогам «Жёлтый от» / «Красный от»; ЦП, диск и ГП —
      среднее за 15 секунд, память — текущая; после «также:» перечислены остальные
      выбившиеся метрики. Названия процессов появляются через 5–10 секунд после
      открытия окна (процессы замеряются раз в 5 секунд, пока окно открыто). Справа в полосе кнопка «Закрыть <процесс>»
      (если виновник определён и его можно завершать): первый клик спрашивает «Точно
      закрыть?», второй в течение 5 секунд завершает процесс (все его экземпляры).
      Системные процессы, проводник и сам виджет не предлагаются;
    * чипы в шапке: «2 мин» / «15 мин» / «1 ч» / «24 ч» — период графика;
      на «1 ч» и «24 ч» точка — среднее за минуту, тонкая линия над ней — пик;
    * при наведении на график — линия, точка и подпись: момент и значение
      (на «1 ч» и «24 ч» — время на часах и пик этой минуты; «нет данных»,
      если виджет тогда не работал);
    * окно тянется за заголовок (двойной клик по заголовку разворачивает
      его), размер меняется за края; закрывается «✕», Esc или повторным
      нажатием «▦»; отдельного значка на панели задач у него нет;
    * высота окна подгоняется под строки сама: без пустого места под последней
      и без обрезанной строки (если строки не помещаются на экран, окно
      упирается в рабочую область и строки прокручиваются);
    * размер, место и период запоминаются (dashboard.json).

  Меню строки
    * правый клик по строке карточки — «Скрыть строку»; это быстрее,
      чем идти в окно настроек;
    * «Скрыть строку» действует так же, как снятый чип в настройках:
      у одного из нескольких дисков скрывается только он, у
      единственного диска — вся строка дисков;
    * последнюю видимую строку скрыть нельзя — появится плашка
      «Последнюю строку скрыть нельзя»; скрытое возвращается через
      настройки или меню.

  Значок в трее
    * «цифровой дождь» — четыре потока капель; дождь идёт постоянно,
      поэтому значок живой;
    * когда ОЗУ, ЦП, диск или ГП доходят до 90 %, дождь становится
      красным — тревога видна в трее, не открывая карточку;
    * двойной клик — показать/скрыть карточку;
    * правый клик — то же меню;
    * при наведении — подсказка с именем виджета «SysWidget», без
      процентов: метрики и так видны на карточке;
    * на слабом компьютере анимацию можно выключить в настройках
      (Система → «Анимация значка»): дождь остановится — капли встанут
      на нижнюю границу — и значок перестанет перерисовываться.

  Меню
    Скрыть виджет / Показать виджет   (с подписью сочетания клавиш)
    Освободить память
    ──────────────────────────
    Оповещения            вкл/выкл
    Периферия             вкл/выкл строки устройств
    Поверх всех окон      вкл/выкл
    Запускать при входе   создаёт ярлык в «Автозагрузке»
    ──────────────────────────
    Окно мониторинга
    Настройки…
    Выход

    Включённые переключатели отмечены галочкой слева.

  Настройки
    Окно настроек — пять вкладок: «Карточка», «Вид», «Данные»,
    «Тревоги», «Система».
    * «Карточка»: КАРТОЧКА — «Строки карточки»: ОЗУ, ЦП, Диск, ГП,
      Сеть, Периф.; снять можно все, кроме последней видимой строки —
      пустая карточка не нужна (при двух и более дисках ниже — чипы
      отдельных дисков); РАСКЛАДКА — «Ориентация» (горизонтально/
      вертикально), «Масштаб» 90 / 100 / 110 / 125 %, «Порядок» строк;
    * «Вид»: ТЕМА И РАЗМЕРЫ — «Тема» (Неон / Тёмная / Светлая),
      «Плотность» (Компактно / Обычно / Свободно), «Шрифт» (90 / 100 /
      110 / 120 %); ПРОЗРАЧНОСТЬ И ПОДПИСИ — «Прозрачность» 40–100 %,
      «Бледнеть в простое», «Подписи» (Текст / Скрыты), «Кнопка «▦» на
      карточке»; ЦВЕТА МЕТРИК; ЦВЕТ ПО НАГРУЗКЕ — «Менять цвет числа»,
      «Жёлтый от» и «Красный от» (по умолчанию 70 и 90 %);
    * «Данные»: «Имя Wi-Fi в подсказке», «Лимит трафика в месяц»,
      «Папка данных», «Настройки вида» → «Сбросить»; ОЧИСТКА ДИСКА;
    * «Тревоги»: ОПОВЕЩЕНИЯ — включение, пороги метрик 50–99 %, свободное
      место 1–50 %, заряд периферии 5–50 %, тихие часы (включение и
      границы «Тихо с» / «Тихо до» с шагом 30 минут);
    * «Система»: СИСТЕМА — «Поверх всех окон», «Запускать при входе»,
      «Анимация значка» (для слабых машин); ЯЗЫК — «Русский» /
      «English»; затем «Показать / скрыть» (сочетание клавиш, только
      показывается; если его заняла другая программа, написано «занято другой
      программой»), РАСШИРЕННЫЕ ДАННЫЕ, ОБНОВЛЕНИЯ, АВТОЗАГРУЗКА,
      КРУПНЫЕ ПАПКИ, СОБЫТИЯ WINDOWS. Язык переключается сразу, без
      перезапуска: карточка, меню, трей, монитор, настройки и ярлык
      в «Пуске».

  «Вертикально» — карточка встаёт столбиком. На панели задач она
  ставится низом на край экрана и растёт вверх, размер не уменьшается.

  Всё выбранное запоминается и восстанавливается при следующем запуске,
  в том числе язык интерфейса и раскладка карточки.

----------------------------------------------------------------------
ОПОВЕЩЕНИЯ
----------------------------------------------------------------------

 Когда ОЗУ, ЦП, диск или видеокарта держатся выше порога (по умолчанию
 90 %) дольше 10 секунд, появляется красная плашка. Повторное
 напоминание по той же метрике — не чаще раза в 10 минут. Короткие
 пики и первые 20 секунд после запуска не считаются. Небольшие провалы
 ниже порога (до 5 пунктов) отсчёт не сбрасывают: нагрузка, прыгающая
 вокруг порога, всё равно сработает.

 Тревога по ЦП или ОЗУ кликабельна: клик по плашке открывает «топ
 процессов».

 Тихие часы (по умолчанию выключены, 23:00–07:00): в это время нет ни
 плашек, ни уведомлений. Включаются в настройках («Тревоги»).

 Ещё две тревоги срабатывают, когда значение НИЖЕ порога:

   * свободного места на диске меньше 10 % — «Диск C: · свободно …»;
     проверка идёт раз в минуту;
   * заряд подключённой периферии ниже 20 % — «Мышь 15% · низкий
     заряд». Когда устройство подзарядили выше порога, тревога по
     нему снова разрешается.

 Если задан «Лимит трафика в месяц» (Настройки → «Данные»), при 80 % и
 при 100 % лимита появляется плашка «Трафик за месяц … из … ГБ (…%)»;
 по умолчанию лимит выключен.

 Если карточка скрыта в трей, вместо плашки показывается уведомление
 от значка. Поверх полноэкранной игры, презентации и режима
 фокусировки Windows уведомления не показываются. Когда на мониторе
 полноэкранное окно, карточка сама прячется и возвращается после.

 Если монитор отключили или сменилось разрешение, карточка сама
 возвращается в видимую область экрана.

----------------------------------------------------------------------
ПРОВЕРКА НА НОВОЙ МАШИНЕ
----------------------------------------------------------------------

 1) Запуск: карточка и значок в трее появились.
 2) Значения ОЗУ/ЦП/диска/ГП/сети меняются раз в секунду. У видеокарты
    может стоять «—», если Windows не отдаёт счётчики GPU (старая версия
    Windows или драйвер). Остальное при этом работает.
  2а) Значок в трее — дождь; при загрузке от 90 % он краснеет.
 3) Наведите на строку метрики — она лишь слегка подсвечивается,
    подсказок при наведении нет. Вся информация — в плашке по клику:
    сверху сводка (у ОЗУ объём, кэш и модель, у ЦП частота и модель,
    у диска чтение/запись, тома и место, у ГП видеопамять и адаптер,
    у сети подключение, пинг и трафик) и мини-график за 2 минуты со
    строкой «за N мин: ср … · макс …», ниже — список процессов.
    Подсказка самой карточки на пустом месте — «Правый клик — меню»;
    у кнопок «молния», «▦» и «⚙» есть свои подсказки.
 3а) Скачайте что-нибудь — «Сеть ↓…» должна показать скорость, близкую
    к реальной; при простое там «↓0.0 ↑0.0».
 3б) Кликните по строке ЦП, затем ОЗУ, диска, ГП и сети — над карточкой
    должна появиться плашка «топ процессов»; повторный клик закрывает её.
    У ЦП под списком столбики по ядрам и частота, у ОЗУ — итог по памяти и
    метка ↗ у растущих процессов, у диска — чтение/запись процессов,
    состояние диска и свободное место, у ГП — загрузка процессов и
    нагрузка по движкам, у сети — процессы с числом соединений
    (адреса — в подсказке строки процесса) и график трафика за 30 дней.
    Лимит трафика в месяц — Настройки → «Данные»: при 80% и 100% появится
    предупреждение. Клик по строке периферии открывает плашку устройства:
    заряд, прогноз «хватит ещё на …», график за 14 дней и журнал
    подключений (история копится с первого запуска этой версии). Крестик
    требует второго клика («Завершить?») — не завершайте нужное.
 3в) Ctrl+Alt+W прячет и возвращает карточку.
 4) Перетащите карточку на панель задач — она не должна за неё
    прятаться.
 5) Клик по пустому месту карточки ничего не открывает — так и
    задумано; клик по строке метрики или периферии открывает плашку.
 6) Правый клик по карточке и по значку — меню в стиле карточки, пункты
    работают; включённые переключатели отмечены галочкой, при
    переключении подписи не сдвигаются; правый клик по строке — меню
    «Скрыть строку», скрытая строка исчезает, последнюю скрыть нельзя.
 7) «Настройки…» — вкладки «Карточка», «Вид», «Данные», «Тревоги»,
    «Система»; меняются строки, ориентация, масштаб, порядок, пороги и
    язык; изменения видны сразу.
 8) «Освободить память» — плашка «Освобождено … Больше всего держит X». Программа,
    с которой вы работаете сейчас, не затрагивается; фоновым программам память урезается.
 9) Перезапустите программу — место, вид и язык восстановились.
10) Если мониторов два с разным масштабом — при переносе карточки она
    остаётся резкой и не прыгает.
11) Оповещения о нехватке места и заряда: временно поднимите порог
    «Свободно на диске» (Настройки → «Тревоги») до максимума — 50 %.
    Если на диске C: свободно меньше половины, в течение минуты должна
    появиться плашка «Диск C: · свободно …»; верните порог обратно
    (по умолчанию 10 %).
12) Отступы: по краям карточки (сверху, снизу, слева, справа), между
    строками и между кнопками «молния», «▦» и «⚙» зазор одинаковый.
    Настройки → «Вид»: плотность, шрифт, тема и цвета (после них нужен
    перезапуск — кнопка «Перезапустить» в окне), прозрачность, бледнение в
    простое, подписи и цвет по нагрузке — сразу.
13) Настройки → «Данные» → «ОЧИСТКА ДИСКА»: «Проверить» показывает объём
    по категориям, ничего не удаляя; «Очистить» удаляет отмеченное
    (временные файлы старше суток, отчёты об ошибках, кэш значков/
    эскизов/шейдеров, кэш браузеров); если проверки ещё не было, первое
    нажатие «Очистить» сначала запускает проверку. Корзина, «Загрузки»,
    пароли и куки не затрагиваются; занятые файлы пропускаются.
14) Настройки → «Система» → «ОБНОВЛЕНИЯ» → «Проверить» (до минуты):
    группы «WINDOWS», «ДРАЙВЕРЫ (НЕОБЯЗАТЕЛЬНО)» и «ПРОГРАММЫ» — зелёное
    «✓ актуально», жёлтое «● N доступно» или красное «⚠ ошибка».
    Программы проверяются через winget; если его нет (Windows 10 без
    «Установщика приложений»), будет «winget не установлен» — это
    нормально. «Обновить» открывает видимое окно winget; обновления
    Windows ставятся в Центре обновления (кнопка «Центр обновления»
    рядом).
15) Значок геолокации в трее не должен мигать: имя Wi-Fi в подсказке сети
    выключено по умолчанию (Настройки → «Данные» → «Имя Wi-Fi в
    подсказке»). Если включить — Windows будет показывать значок раз в
    5 минут (в списке «Оболочка сетевых команд»).
16) Плашка ЦП: в сводке строка «Потребление … Вт (ядра … Вт)» (если Windows
    отдаёт счётчик) и частота ядра в подсказке столбика. Расширенные данные:
    Настройки → Система → «Подключить» → подтвердить UAC → статус
    «подключено»; плашка диска покажет температуру и износ SSD. «Отключить»
    или выход из виджета закрывает процесс с правами администратора
    (проверьте в диспетчере задач, что второго SysWidget.exe не осталось).

17) Настройки → «Система» → «АВТОЗАГРУЗКА»: список того, что запускается при
    входе в Windows (реестр Run пользователя и всех пользователей, папки
    «Автозагрузка» пользователя и всех пользователей; кнопка «Обновить»
    перечитывает список, «Все (N)» раскрывает его целиком). У каждой записи —
    источник, издатель, текущее потребление памяти и ЦП и плашка «влияние»
    (низкое / среднее / высокое / не запущено / отключено). «Отключить»
    работает для ваших записей без прав администратора (как в диспетчере
    задач: запись не удаляется, флаг ставится в StartupApproved), «Включить»
    возвращает её. Действует со следующего входа; запущенную программу не
    закрывает. Записи «для всех пользователей» и сам виджет только
    показываются. «Влияние» — оценка по потреблению процессов сейчас, а не
    замер времени загрузки Windows.
18) Если страница настроек длиннее экрана (например, много записей автозагрузки),
    она прокручивается колесом мыши или тонкой полосой справа; шапка с
    вкладками и плашка «нужен перезапуск» остаются на месте.

19) Окно настроек можно растягивать: за правый край — по ширине, за нижний край —
    по высоте, за правый нижний угол — по обеим сторонам (курсор меняется на
    стрелки). Чем шире окно, тем длиннее строки и тем ниже страница: текст-пояснения
    сам переносится по словам. Двойной клик по нижнему краю возвращает высоту
    «по содержимому». Размер запоминается в window.json (SettingsWidth,
    SettingsHeight); меньше обычной ширины окно не делается.

20) Настройки → «Система» → «КРУПНЫЕ ПАПКИ» → «Сканировать»: диск C: обходится в
    фоне (около минуты, до 3 минут на большом диске; ничего не удаляется).
    Результат: сверху «Занято … из … · просмотрено … (N%)», ниже папки
    верхнего уровня с полосой доли; клик по строке раскрывает вложенные папки
    (три уровня), «↗» показывает папку или файл в проводнике; отдельным списком
    10 самых больших файлов (файл подкачки, hiberfil и т. п.). Охват меньше
    100 % — норма: системные папки без прав администратора недоступны; ссылки
    (junction) не обходятся, «облачные» файлы OneDrive не считаются, а WinSxS
    считается по длине файлов и из-за жёстких ссылок может выглядеть больше,
    чем занимает на диске.
21) Настройки → «Система» → «СОБЫТИЯ WINDOWS»: при первом открытии раздела сам
    читает журналы «Приложение» и «Система» за 7 дней (только чтение, права
    администратора не нужны; кнопка «Обновить» — перечитать). Сверху плашка:
    «✓ За последние сутки сбоев нет» или «● За сутки: перезагрузки: 1,
    приложения: 3» (красная — перезагрузки без завершения, синие экраны, ошибки
    диска и оборудования). Ниже по группам — ПЕРЕЗАГРУЗКИ И СИНИЕ ЭКРАНЫ,
    ОБОРУДОВАНИЕ И ДРАЙВЕРЫ (WHEA, сброс видеодрайвера), ДИСК, СЛУЖБЫ, СБОИ
    ПРИЛОЖЕНИЙ: одинаковые события сложены в «×N за сутки / за 7 дн.», с временем
    последнего и подробностью (модуль сбоя, код остановки синего экрана).
22) Окно настроек в стиле карточки: каждый раздел — модуль в тонкой рамке (как группы
    ОЗУ/ЦП), у заголовка цветная полоска метрики. Наведите мышь на раздел — рамка
    светлеет и появляется лёгкая заливка; на чипах («Вкл/Выкл», размеры, «−»/«+»)
    наведение даёт цветной отклик, как на карточке. В неон-теме углы почти острые,
    в тёмной и светлой — скруглённые (радиусы берутся из темы, а не заданы числами).
23) Окно мониторинга: кнопка «▦» на карточке (между «⚡» и «⚙») или пункт «Окно
    мониторинга» в меню значка в трее. Под заголовком полоса «что нагружает ПК»:
    «Всё в порядке» (зелёная точка) или жёлтая/красная с названием виновника
    (нагрузите ЦП — например, запустите тяжёлую программу — и через 5–10 секунд
    там появится её имя). Одна строка на ОЗУ, ЦП (со столбиками по
    ядрам), каждый диск, ГП и сеть: слева значение и «за N: ср … · макс …»,
    в середине график со шкалой времени, справа подробности (первая строка
    выделена). Чипы «2 мин / 15 мин / 1 ч / 24 ч» меняют период графика: на «1 ч» и
    «24 ч» видна история по минутам (сразу после первого запуска она короткая,
    за сутки заполняется постепенно, а после перезапуска не пропадает — файл
    history.txt). Наведите мышь на график: линия, точка и подпись с моментом и
    значением (на длинных периодах ещё пик минуты). Значение желтеет и
    краснеет по порогам «Жёлтый от» и «Красный от» (Настройки → «Вид»). Окно можно тянуть за заголовок и менять по
    ширине; высота подгоняется под строки сама. Закрывается «✕», Esc или
    повторным нажатием «▦»; на панели задач отдельного значка нет. Размер, место и
    период запоминаются (dashboard.json). Кнопку «▦» можно скрыть: Настройки →
    «Вид» → «Кнопка «▦» на карточке».
24) Светлая тема: Настройки → «Вид» → «Тема» → «Светлая» (рядом «Неон» и «Тёмная»);
    после выбора нужен перезапуск.
25) Настройки → «Данные»: «Папка данных» → «Открыть» показывает папку с файлами
    настроек в проводнике; «Настройки вида» → «Сбросить» возвращает
    плотность, шрифт, цвета, прозрачность и подписи к значениям по умолчанию
    (выбранная тема остаётся как есть).

 Что должно появиться в папке данных (%LOCALAPPDATA%\SysWidget, а в
 переносном режиме — рядом с exe): state.json, alerts.json, window.json,
 через минуту — traffic.json (остальные файлы — по мере использования).

----------------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК
----------------------------------------------------------------------

 Карточка не появилась
   Проверьте значок в трее (возможно, программа уже была запущена и
   карточка скрыта): двойной клик по значку. Повторный запуск exe тоже
   показывает скрытую карточку.

 Настройки не сохраняются после перезапуска
   Посмотрите, нет ли файла error.log в %LOCALAPPDATA%\SysWidget. Если в
   переносном режиме папка на флешке только для чтения, скопируйте
   папку в профиль или удалите portable.flag.

 Виджет появился второй кнопкой на панели задач
   Запустите программу через ярлык «Виджет системы» из меню «Пуск»
   либо обычным exe из папки. Если ярлык был удалён, он создастся заново
   при следующем запуске.

 Не показываются проценты видеокарты
   Счётчики GPU есть в Windows 10 начиная с версии 1709. На некоторых
   сборках и драйверах они недоступны — карточка показывает «—».

 «Windows защитила ваш компьютер»
   Файл не подписан цифровой подписью. «Подробнее» → «Выполнить всё
   равно». Для проверки на своей машине это безопасно.

 Программа не запускается
   Убедитесь, что SysWidget.exe.config лежит рядом с exe, и что в
   системе есть .NET Framework 4.8.

----------------------------------------------------------------------
КАК УДАЛИТЬ
----------------------------------------------------------------------

 1) В меню программы: «Выход».
 2) Если включали автозапуск — выключите его до выхода («Запускать при
    входе») либо удалите ярлык SysWidget.lnk из «Автозагрузки».
 3) Удалите папку SysWidget и папку настроек %LOCALAPPDATA%\SysWidget.
 4) При желании удалите ярлык «Виджет системы» («System widget» в
    английском интерфейсе) из меню «Пуск».
 5) Если отключали записи в списке автозагрузки (Настройки → «Система»),
    их флаги остались в вашей ветке реестра StartupApproved; перед
    удалением верните записи кнопкой «Включить», если они нужны.

 Программа не оставляет после себя ничего, кроме этих файлов, ярлыков и
 флагов StartupApproved.
